# ResilioAI Core

ResilioAI Core extends the existing Next.js app with a dedicated `/ai-agent` dashboard and server-side AI orchestrator. The original dashboard is available at `/workspace`; the original `/api/agent` URL remains as a compatible entry point to the live orchestrator.

For environment setup, local development, data-source behavior, database migrations, security limits, and Vercel deployment, see [`README.md`](README.md).
