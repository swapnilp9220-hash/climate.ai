# ResilioAI Core web app

This directory is the Vercel project root. See the repository [README](../README.md) for local setup, server environment variables, data integrations, migrations, security notes, and deployment steps.

The application uses Next.js 16, React 19, Prisma/PostgreSQL, server-side OpenAI function calling, and the App Router. Use `npm run dev`, `npm test`, `npm run build`, and `npx prisma migrate deploy` from this directory.
